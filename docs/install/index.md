# Installation

PNLCS is a Laravel application. It runs anywhere PHP 8.4, MySQL or MariaDB and
a web server are available. Pick the way that fits you:

| Way | Best for | Time |
|---|---|---|
| [Docker](docker.md) | Trying PNLCS, or running it as one container | About 5 minutes |
| [On your own server](native.md) | A VPS or dedicated server you control (Ubuntu, Debian, AlmaLinux, Rocky) | About 30 minutes |
| [Inside a hosting-panel account](hosting-panel.md) | A server that already runs Panelica, cPanel or a similar panel | About 20 minutes |

Before you start, check the [requirements](requirements.md).

After installation:

- [First Login](../getting-started/first-login.md) and the
  [Setup Checklist](../getting-started/setup-checklist.md) turn a fresh install
  into one that can take orders.
- [Updating](updating.md), [Backups](backups.md) and the
  [Security checklist](security.md) keep it healthy.

!!! tip "Just looking?"
    The [live demo](https://hosting.panelica.com/) is a real installation you
    can click around without installing anything.
